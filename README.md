# 36 Questions - Couples Intimacy App

A modern React app based on Arthur Aron's groundbreaking 36 Questions research for building deep intimacy between couples.

## Features

✨ **All 36 Original Arthur Aron Questions**
- Scientifically designed progression from light to deepest vulnerability
- Structured in 3 phases for gradual emotional deepening

📓 **Handwritten Notebook Companion**
- Each partner keeps their own physical notebook
- App tracks progress, notebooks record the memories
- Decorate with photos and sketches throughout the journey

🎁 **7 Milestone Reward Activities**
1. Q3: First Spark (Movie Night)
2. Q6: Growing Close (Couples Playlist)
3. Q11: Mystery Gift Exchange
4. Q17: Deep Conversations (Board Game Night)
5. Q22: Creating Together (Creative Photo Shoot)
6. Q24: Opening Up (Sunset on Rooftop)
7. Q28: Visualize Together (Vision Board)
8. Q36: Weekend Getaway (Victory Celebration)

⏱️ **Shared Timer**
- Optional 15-minute timer per question
- Both partners see the same countdown

🔐 **Session Codes**
- Create unique codes to sync between partners
- All data stays private on your devices
